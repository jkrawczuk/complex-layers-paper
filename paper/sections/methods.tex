\section*{Methods}

\subsection*{Dataset}
We use two datasets: one real benchmark and one synthetic benchmark.

\subsubsection*{Real-data benchmark: \texttt{colon\_cancer}}
We use the \texttt{colon\_cancer} dataset (\texttt{data/colon\_cancer.csv}), originally introduced by
\cite{alon1999}. It is a gene-expression microarray benchmark built from colon tumor and normal tissue samples.
In the commonly used machine-learning representation, the data matrix contains:
\begin{itemize}[noitemsep]
\item 62 objects (samples),
\item 2,000 gene-expression features,
\item binary labels: \texttt{tumor} (40) and \texttt{normal} (22).
\end{itemize}

Dataset provenance and time point:
\begin{itemize}[noitemsep]
\item source study: Alon et al., Proceedings of the National Academy of Sciences, 1999 \cite{alon1999};
\item biological domain: human colon adenocarcinoma tissue vs.\ normal colon tissue;
\item benchmark age: a long-standing dataset used continuously since 1999.
\end{itemize}

This dataset is widely recognized as a classical reference problem for sparse learning and feature selection in
bioinformatics, with representative comparative results in \cite{guyon2002,dudoit2002,li2004}.

\subsubsection*{Synthetic benchmark with known signal strength}
To assess feature recovery directly, we additionally generate a synthetic binary classification dataset
(\texttt{data/synthetic\_signal.csv}) with accompanying metadata
(\texttt{data/synthetic\_signal.metadata.json}). The synthetic benchmark is designed to separate predictive
performance from feature-discovery quality.

The final synthetic dataset used in this study has:
\begin{itemize}[noitemsep]
\item 100 samples,
\item 2,000 features in total,
\item balanced classes: 50 negative and 50 positive samples,
\item 12 informative features,
\item 36 redundant features,
\item 1,952 noise features.
\end{itemize}

The signal structure is organized into three latent blocks. Each block contains four informative features and
twelve redundant features. Informative features are indexed first, followed by redundant features, and finally
the noise features. The three signal blocks have decreasing strengths of $1.2$, $0.9$, and $0.6$.

For each block, we first sample a latent Gaussian variable. Then, the four informative features assigned to that
block are generated as noisy linear measurements of the corresponding latent variable, with within-block weights
decreasing from stronger to weaker features and alternating in sign. This construction produces a known ranking
of informative-feature strengths within and across blocks.

Redundant features are then generated as noisy correlated surrogates of the informative features from the same
block. Each redundant feature is linked to one informative feature and also receives a smaller contribution from
the block latent variable. Noise features are generated independently and are unrelated to the class label.

The class label is not generated from a single flat linear combination of all observed features. Instead, it is
constructed from the three latent block signals. The block contributions are summed with their block strengths,
Gaussian label noise is added, and the final continuous score is thresholded at the median so that the resulting
dataset is exactly class-balanced.

After generation, all feature columns are standardized by z-scoring. As a result, the feature variances are on
a common scale, but the signal-to-noise ratios remain different across informative, redundant, and noise
features.

The metadata file stores the exact indices of informative, redundant, and noise features, the block structure,
the informative-feature weights, and the ranking by absolute informative weight. This makes it possible to
evaluate not only predictive accuracy, but also how much of the true informative signal is captured by each
neuron and by the cumulative sequence of neurons.

\subsection*{Model family}
The core model is a complex-layer classifier that sequentially trains sparse linear neurons and removes selected
features after each neuron. This construction follows the Complex Layers of Formal Neurons line of work
\cite{bobrowski2021,bobrowski2022}. For analysis, we treat neuron depth $n$ as a model dimension in its own
right. For each depth, we inspect both the prediction of the $n$-th neuron itself and the cumulative prediction
obtained by majority voting over the first $n$ neurons.

The label \texttt{cpl} refers to the convex piecewise-linear base learner implemented for this study. Its
objective combines hinge loss with L1 regularization; both terms are convex piecewise-linear, so the resulting
sparse linear neuron can be trained as a linear programming problem. It is evaluated as one possible base
learner inside the same complex-layer protocol as the two standard sparse linear baselines.
Base learners evaluated in this study:
\begin{itemize}[noitemsep]
\item \texttt{cpl}: convex piecewise-linear neuron trained with the LP-based hinge + L1 formulation used in the reported experiments.
\item \texttt{svm}: LinearSVC (squared hinge loss + L1 regularization).
\item \texttt{logreg}: logistic regression with L1 regularization.
\end{itemize}
The use of L1-type regularization is motivated by its long-standing role in sparse estimation and feature
selection for high-dimensional problems \cite{tibshirani1996lasso,ng2004l1l2}. For logistic regression, the
computational perspective is closely related to regularization-path methods such as \texttt{glmnet}
\cite{friedman2010glmnet}, while the practical large-scale linear classification setting is represented by
\texttt{LIBLINEAR} \cite{fan2008liblinear}.

\subsection*{Evaluation protocol}
For both benchmarks, we use repeated stratified cross-validation with fixed random seed passed to the splitter.
The primary real-data benchmark reported in this manuscript uses 10 folds and 10 repeats
(100 train/test splits in total) on \texttt{colon\_cancer}. The synthetic benchmark uses the same evaluation
pipeline and can be run with the same or lighter repeated-CV settings depending on computational budget.
The split-wise protocol is important in this setting because feature selection bias is a well-known failure
mode in high-dimensional gene-expression studies when selection and evaluation are not strictly separated
\cite{ambroise2002,krawczuk2016feature}.

\subsection*{Regularization calibration}
Because the three base learners use different optimization schemes and induce sparsity at different rates,
their regularization parameters are not directly comparable on a shared numerical scale. To make the comparison
more interpretable, we calibrate two representative regularization settings for each model on each dataset.

The calibration procedure is intentionally simple. For a given dataset, model, and value of $C$, we fit only
the first neuron and record the number of selected features. We then choose two values of $C$:
\begin{itemize}[noitemsep]
\item a \textbf{low-feature} setting targeting approximately five selected features in the first neuron;
\item a \textbf{high-feature} setting targeting approximately twenty-five selected features in the first neuron.
\end{itemize}

This calibration does not make the models equivalent, but it places them in roughly comparable sparsity
regimes before the full repeated-CV experiments are run.
This choice follows the broader methodological view that comparisons between sparse learners should distinguish
the induced sparsity regime from the raw numerical value of the regularization parameter itself
\cite{ng2004l1l2,saeys2007review}.

For each split:
\begin{enumerate}[noitemsep]
\item The model is trained only on the training fold.
\item A sequence of up to 31 neurons is fitted.
\item After each neuron fit, features with non-zero coefficients are removed from the candidate pool
for subsequent neurons.
\item Predictions are computed on the held-out test fold.
\end{enumerate}

For each split and neuron depth $n$:
\begin{itemize}[noitemsep]
\item \textbf{vote prediction}: majority vote over the first $n$ neurons;
\item \textbf{weighted vote prediction}: vote over the first $n$ neurons with weights estimated only from the
training fold;
\item \textbf{neuron prediction}: prediction of the $n$-th neuron only.
\end{itemize}

For the weighted vote, each neuron receives a non-negative quality score derived from its training-fold
balanced accuracy:
\[
q_j=\max\left(0,\mathrm{BA}^{\mathrm{train}}_j-0.5\right),
\qquad
w_j=\frac{q_j}{\sum_{\ell=1}^{n} q_\ell}.
\]
If all $q_j$ are zero, the implementation falls back to uniform weights. The chance-level offset of 0.5 makes
neurons with no above-chance balanced accuracy contribute zero weight. Because all weights are computed on the
training fold, this procedure does not use held-out labels.

Then, for each neuron index $n$, metrics are averaged over all 100 splits.

Reported metrics:
\begin{itemize}[noitemsep]
\item \textbf{vote\_accuracy}: mean accuracy of majority vote over first $n$ neurons;
\item \textbf{weighted vote metrics}: mean held-out performance of the training-quality weighted vote, reported
in the \texttt{weighted\_vote\_results.csv} artifacts;
\item \textbf{neuron\_accuracy}: mean accuracy of the $n$-th neuron alone;
\item \textbf{features\_nth\_neuron}: mean number of selected features in neuron $n$;
\item \textbf{loss} and \textbf{l1\_norm}: mean training-fold objective components for neuron $n$.
\end{itemize}

For the synthetic benchmark, we additionally report feature-recovery metrics derived from known ground truth:
\begin{itemize}[noitemsep]
\item \textbf{informative\_selected\_nth}: number of truly informative features selected by neuron $n$;
\item \textbf{feature\_precision\_nth}: fraction of features selected by neuron $n$ that are truly informative;
\item \textbf{feature\_weight\_recall\_nth}: fraction of total informative-feature weight captured by neuron $n$;
\item \textbf{cumulative\_feature\_recall}: fraction of informative features recovered by the first $n$ neurons;
\item \textbf{cumulative\_feature\_weight\_recall}: fraction of total informative-feature weight recovered by the first $n$ neurons;
\item \textbf{noise\_fraction\_nth} and \textbf{cumulative\_noise\_fraction}: extent to which later neurons drift toward non-informative features.
\end{itemize}

These metrics are used to characterize the role of successive neurons, not only the final classifier output.
In particular, they allow us to distinguish between three behaviors: early concentration of useful signal,
complementary signal acquisition by intermediate neurons, and late-stage domination by noise.
This emphasis goes beyond pure prediction accuracy and is consistent with prior arguments that feature
selection quality and stability deserve explicit evaluation in high-dimensional settings
\cite{saeys2007review,nogueira2018stability,lukaszuk2024importance}.

Loss definitions are unified across models:
\begin{itemize}[noitemsep]
\item \texttt{cpl}: hinge-loss-based training objective with L1 regularization;
\item \texttt{svm}: squared-hinge training objective with L1 regularization;
\item \texttt{logreg}: logistic-loss training objective with L1 regularization.
\end{itemize}

For binary labels $y_i \in \{-1,+1\}$ and linear score $f(x_i)=w^\top x_i + b$, the objective forms are:
\[
\texttt{cpl}: \quad
\min_{w,b}\ \frac{1}{N}\sum_{i=1}^{N}\max\!\left(0,\,1-y_i f(x_i)\right) + \lambda\lVert w\rVert_1
\]
\[
\texttt{svm}: \quad
\min_{w,b}\ \frac{1}{N}\sum_{i=1}^{N}\max\!\left(0,\,1-y_i f(x_i)\right)^2 + \lambda\lVert w\rVert_1
\]
\[
\texttt{logreg}: \quad
\min_{w,b}\ \frac{1}{N}\sum_{i=1}^{N}\log\!\left(1+\exp(-y_i f(x_i))\right) + \lambda\lVert w\rVert_1
\]

In reported diagnostics, \textbf{loss} corresponds to the empirical hinge, squared-hinge, or logistic-loss component, and
\textbf{l1\_norm} corresponds to the regularization component based on $\lVert w\rVert_1$.
All metrics are reported as mean and standard deviation across splits.

The nominal maximum number of neurons is set to 31; training may stop earlier if no additional non-zero
feature set can be produced.
