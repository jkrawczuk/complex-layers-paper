\section*{Introduction}

High-dimensional biological datasets are challenging for linear classifiers due to the small-sample, many-feature
regime and strong feature redundancy. Layered sparse classifiers provide an interpretable approach by learning
sequential neurons and removing selected features after each step.
This setting is also a classical use case for sparse linear modeling and embedded feature selection
\cite{tibshirani1996lasso,ng2004l1l2,saeys2007review}.

This work focuses on two complementary benchmarks. The first is the colon cancer microarray dataset,
one of the canonical benchmarks in bioinformatics and machine learning for high-dimensional classification
\cite{alon1999,guyon2002,dudoit2002,li2004}. It originates from the colon tumor vs.\ normal tissue profiling
study published in 1999 \cite{alon1999}. Across more than two decades, this benchmark has been repeatedly used
to evaluate feature selection, sparse linear models, and stability of classification when the number of
measured features is much larger than the number of samples \cite{guyon2002,dudoit2002,li2004}. In comparative
studies, this benchmark
typically yields high-80\% to mid-90\% accuracy ranges depending on validation protocol and feature-selection
strategy \cite{guyon2002,dudoit2002,li2004}.

The second benchmark is synthetic and is introduced for a different purpose. Real biological datasets provide
realistic distributional complexity, but they do not reveal the true predictive contribution of each feature.
As a consequence, they are suitable for measuring predictive performance and sparsity, but not for directly
measuring whether a method recovers the genuinely informative variables before drifting toward purely noisy
ones. This distinction is particularly important in high-dimensional gene-expression studies,
where feature selection and classifier evaluation can become confounded by selection bias if the protocol is
not carefully separated across training and test data \cite{ambroise2002,krawczuk2016feature}. To address
this limitation, we add a synthetic binary benchmark with known informative features and independent noise
features.
This perspective is also aligned with feature-selection literature emphasizing that selection behavior and
stability should be examined explicitly in high-dimensional classification, not treated merely as secondary
diagnostics after predictive accuracy \cite{saeys2007review,nogueira2018stability,lukaszuk2024importance}.

We compare three methods under the same protocol:
\texttt{cpl}, \texttt{svm}, and \texttt{logreg}. Here, \texttt{cpl} denotes the convex piecewise-linear
base learner used in the complex-layer formal-neuron construction \cite{bobrowski2021,bobrowski2022}: its
hinge-loss objective with L1 regularization is convex and piecewise linear, which allows each sparse neuron to
be trained through linear programming. In contrast,
\texttt{svm} denotes the squared-hinge-loss linear SVM with L1 regularization, and \texttt{logreg} denotes
the corresponding L1-regularized logistic-regression base learner.
The goal is to assess how predictive performance, sparsity,
available depth, and feature-recovery behavior evolve across successive neurons in a controlled repeated
cross-validation setup.
The compared learners are all grounded in well-established sparse linear classification frameworks, including
L1-regularized logistic models and large-scale linear classifiers \cite{friedman2010glmnet,fan2008liblinear}.

Rather than assuming that aggregating many neurons must monotonically improve classification, we study a more
basic question: what does each next neuron contribute, and when can it be constructed at all? In particular,
we ask how much predictive signal is captured by the first neurons, when later neurons still add complementary
information, when later-depth summaries become coverage-dependent, and when selected features become dominated
by noise.

Main contributions:
\begin{enumerate}[noitemsep]
\item A unified complex-layer framework evaluated with three linear sparse learners.
\item A repeated cross-validation benchmark on the classical colon cancer microarray dataset.
\item A synthetic benchmark with known feature relevance for direct feature-recovery analysis.
\item Neuron-by-neuron analysis of accuracy, sparsity, available depth, voting behavior, and feature recovery.
\end{enumerate}
