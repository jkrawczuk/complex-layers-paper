# Paper Workspace

Struktura robocza pod artykul:

- `paper/` - glowna tresc pracy
- `paper/sections/` - sekcje (np. Methods, Results, Discussion)
- `paper/figures/` - finalne figury uzywane w manuskrypcie (np. `figures/colon_cancer/C1/`)
- `paper/tables/` - finalne tabele uzywane w manuskrypcie
- `paper/notes/` - notatki robocze (related work, pomysly, TODO)

Rekomendacja:
- Trzymaj finalne artefakty (figury/tabele) osobno od surowych wynikow (`results/`).

Dodatkowo:
- opis organizacji figur i gridow `5x4` jest w `paper/figures/README.md`
